# Internasionalisasi (i18n) di SIMALUN

## Konteks

SIMALUN / Berkah Kreatif adalah sistem penyewaan papan bunga. Audiensnya
**100% berbahasa Indonesia** — tidak ada rencana multi-bahasa. Infrastruktur
i18n yang dipertahankan hanya yang benar-benar dipakai.

## Struktur file lang

```
lang/
└── id/
    └── validation.php   ← pesan validasi Laravel (dimuat otomatis)
```

Kamus konsolidasi (`ui.php`, `orders.php`, `finance.php`, `messages.php`)
dulu disiapkan untuk memusatkan label, tetapi **tidak pernah dirujuk satu
halaman pun** dan sudah dihapus (lihat §9.43–§9.44 di
`docs/AUDIT-RITME-VISUAL-DAN-GERAK.md`). Kamus yang isinya tidak pernah
tampil justru berbahaya: `orders.php` masih memakai status domain laundry
("Sedang Dicuci", "Disetrika") dan `messages.php` berbunyi "Minimum order Rp
:amount untuk pakai voucher ini." — tidak akan pernah terlihat, jadi tidak ada
yang tahu isinya sudah salah domain.

`UiAccessibilityTest::test_setiap_kamus_bahasa_punya_pemakai` menjaga agar
berkas baru di `lang/id/` selalu punya pemakai (`__('nama.kunci')`,
`trans('nama.kunci')`, atau `@lang('nama.kunci')`) sebelum di-commit.
`validation.php` dikecualikan karena Laravel memuatnya sendiri berdasarkan
nama berkas.

## Cara pakai

### Pesan validasi

Tambahkan kunci di `lang/id/validation.php`; Laravel memuatnya otomatis
berdasarkan nama berkas, tanpa `__()` di view.

### Label halaman

Tulis langsung di view, dalam bahasa Indonesia, satu istilah untuk satu hal:

| Pakai | Jangan |
|---|---|
| kata sandi | password |
| pratinjau | preview |
| pesanan | order |
| atur ulang filter | reset |
| jejak audit | audit trail |
| unggah | upload |
| dasbor | dashboard |

Judul halaman memakai satu pemisah, ` · ` (contoh: `Dasbor Admin · Berkah
Kreatif`); jangan campur dengan ` – ` atau ` | `. Dijaga
`UiAccessibilityTest::test_judul_halaman_memakai_pemisah_titik_tengah`, dan kata
`dashboard` sudah masuk daftar label Inggris yang ditolak.

Dua penjaga menjalankannya: `UiAccessibilityTest::test_tidak_ada_label_inggris_tersisa_di_teks_atau_kamus`
(teks tampil + nilai kamus + placeholder/aria-label/alt/title) dan
`test_kata_password_tidak_tersisa_di_teks_yang_dibaca`.

## Yang BELUM dipusatkan (disengaja)

Label tetap ditulis langsung di view. Untuk aplikasi satu bahasa, memusatkan
semua label menambah satu lapisan tanpa manfaat yang sebanding, dan justru
memisahkan teks dari tata letaknya. Bila nanti benar-benar dibutuhkan
multi-bahasa, pola `__('domain.kunci')` bisa diperkenalkan bertahap per view.

Karena itu, setiap kali sebuah view disentuh (perbaikan tampilan, fitur baru,
perbaikan bug), rapikan sekalian istilah di file itu — bukan lewat satu
sapuan besar.
